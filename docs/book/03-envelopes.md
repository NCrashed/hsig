# Глава 3. Огибающие и ноты

## Огибающая это длина

В hsig нет "длительности ноты" как отдельного поля сигнала. Длину задаёт
огибающая, потому что `(*)` обрезает по короткому аргументу. Отсюда простое
правило: если у сигнала есть огибающая, он конечен, и его можно записать.

Одна и та же волна с разными огибающими это два разных инструмента:

```haskell file=book/Book/Ch03.hs sym=pluck
pluck :: Double -> Sig
pluck f = saw (constant f) * adsr 0.002 0.12 0.2 0.15 0.6 * 0.3
```

```haskell file=book/Book/Ch03.hs sym=pad
pad :: Double -> Sig
pad f = saw (constant f) * adsr 0.4 0.3 0.7 0.8 2.5 * 0.15
```

[`adsr a d s r dur`](glossary.md#adsr) это атака, спад, уровень удержания, отпускание и общая
длина. У щипка атака 2 мс и всё кончается за 0.6 с; у пэда атака 400 мс, и
он тянется 2.5 с. Волна одна, ощущение разное: слух опознаёт инструмент
прежде всего по атаке.

Послушайте [`out/book/03-pad.wav`](../../out/book/03-pad.wav) - три пэда,
сложенные в аккорд.

## Фраза без секвенсора

Пока паттернов нет (они в главе 6), последовательность строится сдвигом и
сложением:

```haskell file=book/Book/Ch03.hs sym=riff
riff :: Sig
riff = mix [delay (0.25 * fromIntegral i) (pluck f) | (i, f) <- zip [0 :: Int ..] phrase]
  where
    phrase = [220, 277.18, 330, 220, 165, 220, 277.18, 330]
```

Здесь важен `mix`, а не `sum`. У `sum` нейтральный элемент это литеральный
`0`, то есть бесконечная константа, и вся фраза стала бы бесконечной - при
записи это упёрлось бы в предел WAV в 4 ГиБ через несколько минут счёта.
`mix` складывает без нейтрального элемента и на пустом списке даёт пустой
сигнал.

Ноты накладываются: спад предыдущей звучит поверх атаки следующей, потому
что `(+)` дополняет короткий сигнал нулями, а не обрезает.
[`out/book/03-riff.wav`](../../out/book/03-riff.wav).

## Огибающая на частоте

Огибающая это обычный сигнал, поэтому её можно подать не на громкость, а
куда угодно. Бочка это синус, у которого высота падает за 20 мс:

```haskell file=book/Book/Ch03.hs sym=kick
kick :: Sig
kick = sine (55 * (1 + 6 * expdecay 0.02)) * adsr 0.001 0.15 0 0.02 0.2 * 0.9
```

`expdecay tau` это мгновенная атака и экспоненциальный спад с постоянной
времени `tau`. В начале ноты множитель равен 7, то есть 385 Гц, через 20 мс
уже около 90 Гц, дальше 55. Ровно так делаются электронные бочки: слышимая
"атака" это высокая часть питч-огибающей.
[`out/book/03-kick.wav`](../../out/book/03-kick.wav).

Обратите внимание: `expdecay` бесконечен, а длину даёт `adsr`. Так и надо -
модулирующая огибающая не обязана заканчивать ноту, это дело амплитудной.

## Инструмент

Инструмент это функция от ноты к сигналу:

```haskell file=book/Book/Ch03.hs sym=plucked
plucked :: Instrument
plucked n =
  saw (constant (noteFreq n))
    * adsr 0.002 0.12 0.2 0.15 (noteDur n)
    * constant (noteAmp n * 0.3)
```

`Instrument` это просто `Note -> Sig`. Планировщик (глава 6) вызовет его для
каждого события паттерна, подставив частоту, длительность и амплитуду.
Длительность приходит из паттерна и уходит в `adsr` - поэтому нота, занявшая
четверть такта, сама себя и закончит.

Контракт один: сигнал инструмента обязан быть конечным. Забыли огибающую -
рендер упадёт с объяснением, а не зависнет.
