# Глава 9. Стемы, кэш и мастер

## Трек это список стемов

```
track :: [Stem]
main = renderTrackWith defaultEnv "out/track.wav" master track
```

Стем это имя плюс сигнал. Панорама и кэш навешиваются поверх, а не
заполняются как поля:

```
stem       :: String -> Sig -> Stem      -- по центру, без кэша
panned     :: Double -> Stem -> Stem
cached     :: String -> Stem -> Stem
stereoStems :: String -> Stereo -> [Stem]
```

Каждый стем рендерится в свой файл, микс собирается из файлов. Причина в
памяти: ленивый список блоков, использованный дважды, удерживается целиком,
а пять минут при 384 кГц это гигабайты на канал. Побочная выгода - стемы
можно слушать по отдельности и считать параллельно.

Вот настоящий трек из `tracks/Demo.hs` целиком:

```haskell file=tracks/Demo.hs sym=track
track :: [Stem]
track =
  [ stem "kick" (kickSig * window * mixLevel)
  , stem "bass" (bus bassLevel (compress 0.04 4 0.005 0.08 (play bassInst (bar "a1 a1 d2 a1"))))
  , panned 0.35 (stem "hat" (bus hatLevel (play hatInst (bar (degradeBy 0.25 "hh*8")))))
  ]
    -- Кэш только на дорогих стемах: лид и реактор считаются десятки секунд.
    -- Версия в строке двигается вместе с правкой патча, длина входит в неё же
    -- (в ключ она не попадает, см. cached).
    <> map (cached (version "лид разд. 9, широкий, v1")) (stereoStems "lead" leadOut)
    <> map (cached (version "реактор, три стержня, v1")) (stereoStems "reactor" reactorOut)
  where
    version s = s <> ", " <> show trackSec <> " с"
```

## Длина берётся из материала

Аргумента длины у рендера нет. Паттерн бесконечен, поэтому стем заканчивает
автор - окном:

```haskell file=tracks/Demo.hs sym=window
window :: Sig
window = gate 0.01 trackSec
```

Аргумент длины пришлось бы держать согласованным с этим окном руками, и
рассогласование давало бы либо обрыв, либо тишину в хвосте. Забытое окно
ловится потолком `envMaxSec` (600 секунд по умолчанию) с объяснением, что
делать; честному треку длиннее потолок поднимают в `Env`.

Общая шина партий тоже живёт в треке, а не в библиотеке:

```haskell file=tracks/Demo.hs sym=bus
bus :: Sig -> Fx
bus level sig = duck sig * window * level * mixLevel
```

## Кэш

По умолчанию кэша нет: стем пишется в `out/<имя>.wav` и считается заново
каждый прогон. Это безопасное поведение - забыть обновить описание
невозможно, потому что его нет.

`cached "строка"` включает кэш: пока строка не изменилась, файл
переиспользуется, а имя получает хэш от строки, `envRate` и `envSeed`.
Строку пишет автор, и она обязана покрывать всё, от чего зависит звук стема,
включая длину: сериализовать `Sig` нечем, это функция. Отсюда идиома с
версией и длиной в строке, которую видно в `track` выше.

Уборка сносит устаревшие версии, но оставляет несколько последних. Это не
жадность, а рабочий цикл: превью на восемь секунд и полный прогон дают разные
ключи, и снос всего, кроме текущего, заставлял бы пересчитывать дорогие стемы
при каждом переключении.

## Мастер

Обработка мастера идёт отдельным аргументом, после сведения:

```haskell file=tracks/Demo.hs sym=master
master :: Stereo -> Stereo
master = bothChannels (shaper 1.2 >>> (* 0.9))
```

Так её правка не трогает стемы и не сбивает кэш: повторный прогон стоит одно
чтение файлов. Лимитера в библиотеке нет намеренно, вместо него насыщение и
трим - в демо-треке это даёт плюс 3 дБ плотности без единого сэмпла у полной
шкалы.
