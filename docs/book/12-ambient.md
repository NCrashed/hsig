# Глава 12. Эмбиент

единого удара.

## Что делает жанр жанром

Убираем ритм - и всё, что держало внимание, исчезает. Держать его теперь
будут три вещи: длинные огибающие, реверберация и медленное движение в
образе.

**Пэд с атакой в секунды.** Та же расстройка, что в электро, но огибающая
растянута на всю ноту:

```haskell file=book/Book/Ch12.hs sym=pad
pad :: Double -> Double -> Sig
pad f dur =
  onepole (700 + 400 * sine 0.07) (mix [voice c | c <- [-7, -2, 3, 9]])
    * adsr (dur * 0.35) (dur * 0.2) 0.7 (dur * 0.45) dur
    * 0.2
  where
    voice cents = saw (constant (f * 2 ** (cents / 1200))) * 0.5
```

Атака это треть ноты, отпускание почти половина, поэтому ноты неизбежно
наползают друг на друга - и это правильно, аккорд собирается сам собой.
Катофф однополюсника медленно дышит на 0.07 Гц (период 14 секунд): без этого
пэд был бы неподвижным.

**[Реверберация](glossary.md#reverb).** Настоящего реверба в библиотеке нет,
но он собирается из [гребёнок](glossary.md#comb) и
[оллпассов](glossary.md#allpass) - классическая схема Шрёдера:

```haskell file=book/Book/Ch12.hs sym=reverb
reverb :: Sig -> Sig
reverb src = allpass 0.005 0.7 (allpass 0.017 0.7 (mix [comb t 0.82 src * 0.25 | t <- times]))
  where
    times = [0.0297, 0.0371, 0.0411, 0.0437]
```

Гребёнки дают плотность отражений, оллпассы размазывают их собственные
резонансы, не меняя амплитудного спектра. Времена подобраны взаимно
непростыми: у кратных времён отражения складываются в слышимый тон, и вместо
зала получается труба.

**Медленное вращение.** Мокрый сигнал водится по кругу за двадцать секунд:

```haskell file=book/Book/Ch12.hs sym=loop
loop :: Stereo
loop = bothChannels (* gate 0.05 20) (mixStereo [orbit angle wet, mono (dry * 0.5)])
  where
    dry = share (mix [delay t (pad f 12) | (t, f) <- [(0, 110), (3, 164.81), (6, 130.81), (9, 220)]])
    wet = reverb dry * 0.9
    angle = 2 * pi * 0.05 * line [(0, 0), (20, 20)]
```

Сухой сигнал остаётся по центру, вращается только мокрый: так источник
никуда не уезжает, а пространство вокруг него живёт. В наушниках это слышно
как медленное дыхание слева направо.

`share` тут обязателен: `dry` входит и в мокрый тракт, и в сухой, а он
недёшев (четыре голоса по четыре расстроенных пилы).

Замер: пик 0.65, среднеквадратичное -21 dBFS, ширина 0.4. Эмбиент имеет право
быть тише и шире танцевальных жанров; выравнивать его по громкости техно
нечем и незачем.

## Чего тут нет

Нет мастер-компрессии: она съела бы дыхание пэдов, ради которого всё и
делалось. Нет и накачки - качать нечем, бочки нет.
