## Что делает жанр жанром

Техно живёт не сменой партий, а медленным изменением одного и того же. Ноты
почти не меняются; меняются фильтр, плотность и шум. Отсюда три приёма.

**Длинный свип поверх статичной ноты.** Бас держит одну ноту 16 секунд, а
катофф уезжает вверх и обратно. Слушатель не замечает, что нот нет:

```
sweep = ladder cutSweep 0.8 (saw 55 * 0.35) * gate 0.02 16
cutSweep = 90 * exp (line [(0, 0), (8, log 30), (16, log 3)])
```

**Стаб вместо мелодии.** Аккорд из трёх пил, короткая огибающая, высокий
[резонанс](glossary.md#cutoff). Играется на слабую долю, и этого хватает как гармонии:

```haskell file=book/Book/Ch11.hs sym=stab
stab :: Instrument
stab n =
  ladder cut 0.85 (mix [saw (constant (noteFreq n * k)) * 0.3 | k <- [1, 1.5, 2]])
    * adsr 0.003 0.09 0.15 0.06 (noteDur n * 0.8)
    * constant (noteAmp n * 0.35)
  where
    cut = 400 + 900 * expdecay 0.05
```

Множители 1, 1.5 и 2 это основной тон, квинта и октава: аккорд собирается
прямо в инструменте, отдельных нот в паттерне для этого не нужно.

**Шумовой подъём.** Полосовой фильтр по шуму, полоса едет вверх шестнадцать
секунд, громкость растёт линейно:

```haskell file=book/Book/Ch11.hs sym=riser
riser :: Sig
riser = svfBand cut 0.9 (noise 7) * line [(0, 0), (16, 0.5)] * 0.6
  where
    cut = 300 * exp (line [(0, 0), (16, log 20)])
```

Это тот самый эффект, который в клубе означает "сейчас будет сброс".

## Сборка

```haskell file=book/Book/Ch11.hs sym=loop
loop :: Stereo
loop = bothChannels (\c -> shaper 1.2 (c * gate 0.02 16 * 0.9)) mixed
  where
    bar = slow 2
    kickSig = share (play kit (bar "bd*4"))
    duck = sidechain kickSig 0.85
    drums = play kit (bar (stack ["bd*4", "[~ hh]*4", "~ ~ ~ sn?0.7"]))
    chords = duck (play stab (bar (every 8 (fast 2) "~ a3 ~ [c4 e4]"))) * 1.4
    sweep = ladder cutSweep 0.8 (saw 55 * 0.35) * gate 0.02 16
    cutSweep = 90 * exp (line [(0, 0), (8, log 30), (16, log 3)])
    mixed = mixStereo [mono drums, mono (duck sweep * 1.2), pan 0.3 chords, pan (-0.2) (duck riser)]
```

Два места стоит отметить.

`"[~ hh]*4"` это хэт на слабую долю: группа из паузы и удара повторяется
четыре раза за цикл, то есть удар приходится ровно между долями. Так
собираются офф-бит рисунки без арифметики со смещениями.

Накачка глубже, чем в электро (0.85 против 0.7), и стоит на всём, включая
шумовой подъём. В техно накачка это не служебная мера, а слышимая часть
ритма: она дышит там, где нет нот.

Замер: пик 0.88, среднеквадратичное -17 dBFS, ширина 0.09. Узкий образ здесь
уместен - в клубе всё, что не по центру, теряется.
