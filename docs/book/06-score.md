# Глава 6. Партитура

## Паттерн это функция от времени

Слой партитуры взят из Tidal один в один: `Pattern a` это функция из отрезка
времени в список событий, время рациональное, цикл равен секунде. Темпа как
отдельного поля нет - его задаёт сам паттерн: `slow 2` это два цикла на такт,
то есть 120 ударов в минуту при четырёх долях.

Строка это паттерн нот (нужен `OverloadedStrings`, в стансе трека и книги он
включён):

- `"bd*4"` - четыре удара в цикл;
- `"~ sn ~ sn"` - паузы и удары через один;
- `"a1 ~ a1 c2"` - имена нот превращаются в частоты (`a1` это 55 Гц);
- `"[bd sn]*2"` - вложенные группы;
- `"hh*16?"` - каждое событие выпадает с вероятностью 0.5.

Слово, которое не является ни нотой, ни числом, остаётся меткой и приходит в
`noteLabel` с нулевой частотой. На этом стоят наборы барабанов:

```haskell file=book/Book/Ch06.hs sym=kit
kit :: Instrument
kit n = case noteLabel n of
  "bd" -> sine (55 * (1 + 6 * expdecay 0.02)) * adsr 0.001 0.15 0 0.02 0.2 * 0.5
  "sn" -> (highpass 1200 (noise 3) * 0.5 + sine 190 * 0.4) * adsr 0.001 0.1 0 0.05 0.18 * 0.45
  "hh" -> highpass 7000 (noise 2) * adsr 0.001 0.04 0 0.01 0.06 * 0.25
  _ -> fromSamples []
```

Неизвестная метка даёт пустой сигнал, а не ошибку: так в паттерн можно
временно вписать голос, которого ещё нет.

## Играем

`play инструмент паттерн` возвращает бесконечный сигнал: события считаются по
мере надобности, нота рендерится инструментом и подмешивается со сдвигом по
своему онсету. Длину, как всегда, задаёт окно.

```haskell file=book/Book/Ch06.hs sym=beat
beat :: Sig
beat = play kit (stack ["bd*4", "~ sn ~ sn", "hh*8"]) * gate 0.01 4
```

`stack` играет паттерны одновременно, поэтому партия ударных это три строки
одна поверх другой: [`06-beat.wav`](../../out/book/06-beat.wav).

Мелодия устроена так же, только инструмент смотрит на частоту, а не на метку:

```haskell file=book/Book/Ch06.hs sym=melody
melody :: Sig
melody = play lead (slow 2 (every 4 rev "a4 c5 ~ e5")) * gate 0.01 8
```

`every 4 rev` разворачивает фразу каждый четвёртый цикл. Это главный приём
всей алгебры: вариация описывается не переписыванием нот, а функцией над
паттерном. [`06-melody.wav`](../../out/book/06-melody.wav) - восемь секунд, то
есть четыре такта, и последний звучит задом наперёд.

Полезный набор: `fast`, `slow`, `rev`, `every`, `degradeBy`, `stack`, `cat`,
`fastcat`, `rotL`, `rotR`. Все с семантикой Tidal, так что чужие рецепты
переносятся почти дословно.

## Разрежение

Ровные шестнадцатые звучат механически. `?` в мини-нотации выбрасывает
события:

```haskell file=book/Book/Ch06.hs sym=sparse
sparse :: Sig
sparse = play kit (stack ["bd*4", "hh*16?"]) * gate 0.01 4
```

[`06-sparse.wav`](../../out/book/06-sparse.wav). Каждый `?` в строке получает
свой поток случайности, поэтому два `?` в одной строке не выпадают
синхронно; долю можно задать явно: `"hh*16?0.3"`. Случайность
детерминированная - тот же паттерн даёт тот же рисунок при каждом рендере,
иначе трек нельзя было бы сводить.
