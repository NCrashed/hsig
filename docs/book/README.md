# hsig: книга

Как пользоваться библиотекой на примерах и как собирать из них разную музыку.
Проект и его ограничения описаны в [DESIGN.md](../DESIGN.md); эта книга не
дублирует дизайн, а показывает работу с ним.

Код каждой главы лежит в `book/Book/ChNN.hs` и собирается вместе с проектом,
а тест `test/BookSpec.hs` сверяет каждый показанный блок с исходником: если
они разойдутся, тесты упадут. Значит всё, что вы здесь видите, компилируется
и звучит.

Звук примеров лежит рядом с главами в [audio](audio) и слушается по ссылкам
прямо из текста. Если правите примеры, пересоберите и перекодируйте:

```
nix develop --command cabal run book   # out/book/*.wav
nix develop --command tools/book-audio.sh   # docs/book/audio/*.mp3
```
