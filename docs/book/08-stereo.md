# Глава 8. Стерео и пространство

## Стерео это пара сигналов

```haskell file=src/Sound/Sig/Stereo.hs sym=Stereo
data Stereo = Stereo
  { leftChan :: Sig
  , rightChan :: Sig
  }
```

Отдельного "стерео-сигнала" нет: `Sig` отдаёт один поток (разд. 3 дизайна),
поэтому всё стерео строится из пары. Отсюда и цена: стерео-инструмент считает
ноту дважды, по разу на канал.

Простейшее размещение это [панорама равной мощности](glossary.md#pan):

```haskell file=book/Book/Ch08.hs sym=sides
sides :: Stereo
sides = mixStereo [pan (-0.8) left, pan 0.8 right]
  where
    left = play kit "hh*8" * gate 0.01 4
    right = play kit "~ sn ~ sn" * gate 0.01 4
```

`pan p` кладёт моно в точку образа, `mixStereo` складывает список стерео.
Равная мощность значит, что суммарная энергия не зависит от положения: на
краях один канал получает всё, по центру каждый получает `1/sqrt 2`.
[`08-pan.mp3`](audio/08-pan.mp3).

## Ширина через расстройку

Панорама двигает источник, но не делает его широким. Ширина берётся из того,
что в каналах звучит не одно и то же:

```haskell file=book/Book/Ch08.hs sym=wide
wide :: Stereo
wide = Stereo (voice (-4)) (voice 4)
  where
    voice cents = saw (220 * constant (2 ** (cents / 1200))) * adsr 0.01 0.2 0.6 0.3 3 * 0.25
```

Восемь [центов](glossary.md#cents) расстройки между каналами, и звук перестаёт быть точкой:
[`08-wide.mp3`](audio/08-wide.mp3). На этом же принципе стоит
широкий [унисон](glossary.md#unison) из приёмочного патча (`patches/Lead.hs`): голоса
раскладываются по образу, и чем больше расстройка, тем шире.

Проверять такое надо в моно: если при суммировании каналов звук проваливается,
значит каналы противофазны, и на клубной системе партия исчезнет.

## Вращение вокруг головы

`orbit angle` это параметрическая бинауральная панорама:
[межушная задержка](glossary.md#itd)
(до 0.65 мс), тень головы (фильтр, зависящий от угла) и разница уровней.
Угол это сигнал, поэтому источник можно возить по кругу:

```haskell file=book/Book/Ch08.hs sym=spinning
spinning :: Stereo
spinning = orbit (2 * pi * 0.5 * ramp) src
  where
    ramp = line [(0, 0), (8, 8)]
    src = play kit "bd*2" * gate 0.01 8 + saw 220 * adsr 0.01 0.3 0.4 0.5 8 * 0.2
```

Половина оборота в секунду, четыре оборота за восемь секунд:
[`08-orbit.mp3`](audio/08-orbit.mp3). Слушать обязательно в
наушниках - в колонках межушная задержка не работает.

Чего `orbit` не умеет: различать перед и зад. За это отвечают складки ушной
раковины, а их параметрической моделью не покрыть; для этого нужна свёртка с
измеренными импульсными характеристиками ([HRTF](glossary.md#hrtf), этап M10
дорожной карты).
Практический вывод: вращение слышно как движение слева направо через голову,
а не как полный круг.

## [Хаас](glossary.md#haas): ширина из задержки

Сдвиг одного канала на 10-30 мс воспринимается не как эхо, а как ширина:

```haskell file=book/Book/Ch08.hs sym=doubled
doubled :: Stereo
doubled = Stereo src (vdelay 0.05 (constant 0.019) (src * 0.9))
  where
    src = share (play kit "hh*8" * gate 0.01 4)
```

[`08-haas.mp3`](audio/08-haas.mp3). `vdelay макс время` это задержка
с дробным временем на интерполяции синком: время задаётся сигналом, поэтому
её можно плавно вести (хорус, доплер). Цена дробной интерполяции - минимум в
8 сэмплов, то есть фленджер сквозь ноль ей не собрать.

В моно такой приём даёт [гребёнку](glossary.md#comb): 19 мс это провалы каждые 53 Гц. Проверяйте
сумму каналов, если трек может играть в моно.
