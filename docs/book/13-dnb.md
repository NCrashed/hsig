# Глава 13. Драм-н-бэйс

[`13-dnb.mp3`](audio/13-dnb.mp3) - одиннадцать секунд на
[174 ударах в минуту](glossary.md#bpm).

## Темп задаётся паттерном

```haskell file=book/Book/Ch13.hs sym=bar
bar :: Pattern a -> Pattern a
bar = slow (240 / 174)
```

Цикл по умолчанию это четыре доли в секунду, то есть 240 ударов в минуту.
Нужно 174 - растягиваем цикл в 240/174 раза. Рационального темпа тут не
требуется: время в паттернах и так рациональное, а число тут обычное.

## Разломанный бит

Основа жанра это два удара бочки на такт в неровных местах и снейр на второй
и четвёртой доле. В мини-нотации это восемь шестнадцатых:

```
"bd ~ ~ bd ~ ~ ~ ~"
"~ ~ sn ~ ~ ~ sn ~"
```

Хэты идут отдельным слоем с разрежением `?0.3`, то есть выпадает примерно
треть - без этого рисунок звучит машинно.

## [Reese](glossary.md#reese)

Главный звук жанра. Две пилы, расстроенные на доли герца, дают биения; если
развести их по каналам, биения превращаются в движение образа:

```haskell file=book/Book/Ch13.hs sym=reese
reese :: Note -> Stereo
reese n = Stereo (voice (-0.4)) (voice 0.4)
  where
    voice d =
      ladder cut 0.7 (mix [saw (constant (noteFreq n + d + s)) * 0.35 | s <- [0, 7]])
        * adsr 0.01 0.1 0.85 0.08 (noteDur n * 0.95)
        * constant (noteAmp n * 0.35)
    cut = 200 + 700 * (0.5 + 0.5 * sine 0.35)
```

Расстройки тут две и они разного порядка. Плюс-минус 0.4 Гц между каналами
дают период биений около секунды - это движение. Ещё 7 Гц внутри канала дают
быстрое биение, из которого получается характерная "рычащая" фактура. Катофф
качается на 0.35 Гц, и рык дышит.

Это `Note -> Stereo`, то есть стерео-инструмент: играется через `playStereo`,
и нота считается дважды, по разу на канал (глава 8).

## Сабмикс

```haskell file=book/Book/Ch13.hs sym=loop
loop :: Stereo
loop = bothChannels (\c -> shaper 1.3 (c * gate 0.02 11 * 0.9)) mixed
  where
    kickSig = share (play kit (bar "bd ~ ~ bd ~ ~ ~ ~"))
    duck = sidechain kickSig 0.5
    break2 = play kit (bar (stack ["bd ~ ~ bd ~ ~ ~ ~", "~ ~ sn ~ ~ ~ sn ~"]))
    bassLine = bothChannels (\c -> duck c * 1.5) (playStereo reese (bar "a1 ~ ~ a1 c2 ~ a1 ~"))
    subLine = duck (play sub (bar "a1 ~ ~ ~ c2 ~ ~ ~")) * 1.2
    hats = play kit (bar "hh*8?0.3")
    mixed = mixStereo [mono break2, pan 0.35 hats, bassLine, mono subLine]
```

Отдельный [саб](glossary.md#sub) - синус в той же тональности, но своим рисунком:

```haskell file=book/Book/Ch13.hs sym=sub
sub :: Instrument
sub n = sine (constant (noteFreq n)) * adsr 0.01 0.05 0.9 0.05 (noteDur n * 0.95) * 0.5
```

Так делают потому, что Reese плохо переносит низ: расстроенные пилы на 55 Гц
дают биения на самой границе слышимого, и в клубе это превращается в гул.
Низ отдают чистому синусу по центру, а Reese живёт выше и в стороне. Именно
поэтому саб и бас качаются от одной бочки, но микшируются по-разному.

Накачка тут слабее, чем в техно (0.5): бочка редкая, и глубокая накачка
резала бы бас в самых интересных местах.

Замер: пик 0.87, среднеквадратичное -14 dBFS, ширина 0.11. Жанр громкий, но
низ по центру, поэтому моно-совместимость сохраняется.
