# Глава 10. Электро

Целевой звук проекта (разд. 1 дизайна): плотное сатурированное электро в духе
Vitalic. Разберём, из чего оно складывается.

Послушайте сначала: [`10-electro.wav`](../../out/book/10-electro.wav) - четыре
такта на 120 ударах.

## Что делает жанр жанром

Три вещи, и все три уже были в части I.

**Расстроенный [унисон](glossary.md#unison).** Лид это не один голос, а семь, разведённых по
частоте на десяток центов и по образу. Биения между ними дают то самое
движение, из-за которого звук кажется живым. Это `leadWide` из приёмочного
патча `patches/Lead.hs`.

**Резонансный фильтр с быстрой огибающей.** Бас без огибающей катоффа звучит
как гудение; с ней у каждой ноты появляется атака:

```haskell file=book/Book/Ch10.hs sym=bassInst
bassInst :: Instrument
bassInst n =
  ladder (180 + 2200 * expdecay 0.07) 0.75 (saw (constant (noteFreq n)) * 0.5)
    * adsr 0.005 0.09 0.5 0.05 (noteDur n * 0.9)
    * constant (noteAmp n * 0.5)
```

Катофф прыгает на 2.4 кГц и падает за 70 мс. Резонанс 0.75 подчёркивает этот
прыжок, и получается характерный "щелчок" в начале ноты.

**Накачка и насыщение.** Бочка качает всё остальное, а на выходе стоит tanh:

```haskell file=book/Book/Ch10.hs sym=loop
loop :: Stereo
loop = bothChannels (\c -> shaper 1.3 (c * window * 0.9)) mixed
  where
    window = gate 0.01 8
    kickSig = share (play kit (bar "bd*4"))
    duck = sidechain kickSig 0.7
    drums = play kit (bar (stack ["bd*4", "~ sn ~ sn", "hh*8"]))
    bassPart = duck (play bassInst (bar "a1 a1 c2 a1")) * 1.8
    lead = bothChannels (\c -> duck c * 0.7) (playStereo leadWide (bar (every 4 rev "a4 c5 ~ e5")))
    mixed = mixStereo [mono drums, mono bassPart, lead]
```

Замер: пик 0.83, [среднеквадратичное](glossary.md#rms) -18 [dBFS](glossary.md#db), ширина 0.2. Плотность тут от
насыщения, а не от громкости - именно поэтому запас по пикам остался.

## Темп

```haskell file=book/Book/Ch10.hs sym=bar
bar :: Pattern a -> Pattern a
bar = slow 2
```

Цикл по умолчанию это секунда и четыре доли, то есть 240 ударов в минуту.
`slow 2` растягивает его вдвое - выходит 120. Никакого поля темпа в
библиотеке нет: темп это свойство паттерна, и разные партии могут идти в
разном темпе, если так задумано.
