# Глава 16. Даунтемпо

[`16-downtempo.mp3`](audio/16-downtempo.mp3) - 86 ударов в минуту, двадцать
четыре секунды.

Жанры из глав 10-13 держатся на энергии. Этот держится на её отсутствии: всё
медленно, редко и слегка криво. Отсюда три приёма, которых раньше не было.

## Кривая сетка

Ровные восьмые на 86 ударах звучат не расслабленно, а мёртво. Лечится
свингом: каждая вторая доля опаздывает.

```haskell file=book/Book/Ch16.hs sym=straight
straight :: Sig
straight = play kit (bar (stack ["bd ~ ~ ~ sn ~ ~ ~", "hh*8"])) * gate 0.01 8
```

```haskell file=book/Book/Ch16.hs sym=swung
swung :: Sig
swung = play kit (swingBy (1 / 5) 4 (bar (stack ["bd ~ ~ ~ sn ~ ~ ~", "hh*8?0.2"]))) * gate 0.01 8
```

Слушайте подряд: [`16-straight.mp3`](audio/16-straight.mp3) и
[`16-swung.mp3`](audio/16-swung.mp3). Ноты те же, разница только в том, что
слабые восьмые сдвинуты на пятую часть шага, и ещё пятая часть хэтов выпала.

`swingBy x n` двигает только вторую половину каждой n-й доли - сильные доли
остаются на месте, иначе поехал бы весь трек. Величина сдвига это вкус: 1/3
даёт джазовый триольный свинг, 1/5 - едва заметную лень, которая и нужна
даунтемпо.

## Шорох

Второй признак жанра - грязь носителя. Виниловый треск это редкие короткие
всплески, и делается он порогом по шуму:

```haskell file=book/Book/Ch16.hs sym=crackle
crackle :: Sig
crackle = onepole 4000 (mapSig spark (noise 21)) * 0.5
  where
    spark v = if abs v > 0.985 then signum v * (abs v - 0.985) * 60 else 0
```

Порог 0.985 оставляет примерно полтора процента сэмплов, вычитание порога
делает всплески разной высоты, а однополюсник срезает верх, чтобы это был
треск, а не цифровой щелчок. [`16-crackle.mp3`](audio/16-crackle.mp3).

Приём общий: любой редкий случайный процесс делается порогом по шуму, а не
генератором событий. Плотность крутится порогом, характер - фильтром после.

## Тёплые тембры

Быстрая огибающая и резонанс тут не нужны, нужна мягкая атака и глухой верх.
Электропиано складывается из трёх синусов, где верхние гаснут быстрее (тот же
принцип, что у колокола в главе 14, но отношения целые, поэтому высота
слышна):

```haskell file=book/Book/Ch16.hs sym=rhodes
rhodes :: Instrument
rhodes n =
  shaper 1.6 (mix [tine 1 1 0.35, tine 2 0.45 0.12, tine 4.02 0.2 0.05])
    * adsr 0.004 0.35 0.45 0.5 (max 0.6 (noteDur n))
    * constant (noteAmp n * 0.45)
  where
    f = noteFreq n
    tine ratio amp decay = sine (constant (f * ratio)) * expdecay decay * amp
```

Четвёртая гармоника чуть расстроена (4.02), и это слышно как лёгкое биение -
без него звук слишком чистый. Насыщение добавляет ту самую тёплую окраску.
[`16-rhodes.mp3`](audio/16-rhodes.mp3).

Бас в этом жанре не должен рычать: синус, немного насыщения и срез сверху.

```haskell file=book/Book/Ch16.hs sym=warmBass
warmBass :: Instrument
warmBass n =
  onepole 320 (shaper 2.5 (sine (constant (noteFreq n)) * 0.8))
    * adsr 0.02 0.15 0.75 0.2 (noteDur n * 0.95)
    * constant (noteAmp n * 0.55)
```

## Сборка

```haskell file=book/Book/Ch16.hs sym=loop
loop :: Stereo
loop = bothChannels (\c -> shaper 1.2 (c * gate 0.05 24 * 0.55)) mixed
  where
    drums = swingBy (1 / 5) 4 (bar (stack ["bd ~ ~ ~ sn ~ ~ ~", "hh*8?0.2", "~ ~ ~ ~ ~ ~ bd ~"]))
    kickSig = share (play kit (bar "bd ~ ~ ~ ~ ~ ~ ~"))
    duck = sidechain kickSig 0.35
    keys = duck (play rhodes (bar (off (1 / 8) (fmap quieter) "a3 ~ c4 ~ ~ e4 ~ ~"))) * 1.2
    bass = duck (play warmBass (bar "a1 ~ ~ ~ f1 ~ ~ ~")) * 1.4
    quieter n = n {noteAmp = noteAmp n * 0.4, noteFreq = noteFreq n * 2}
    mixed =
      mixStereo
        [ mono (play kit drums * 0.9)
        , pan (-0.25) keys
        , mono bass
        , pan 0.3 (crackle * 0.5 * gate 0.05 24)
        ]
```

Три вещи, которых нет в танцевальных главах.

**Накачка слабая** (0.35 против 0.7-0.85). Она тут не ритм, а склейка: бочка
редкая, и глубокое приседание было бы слышно как эффект.

**Клавиши с эхом на октаву выше** через `off` из главы 15 - тот же приём, что
там, но тише и мягче, поэтому воспринимается как призвук, а не как вторая
партия.

**Треск сбоку.** Он в стороне и тихий: его задача не быть слышимым, а
занимать место, где в танцевальной музыке был бы хэт.

Замер: пик 0.77, среднеквадратичное -15 dBFS. Жанру положено быть тише и
динамичнее танцевального: у техно из главы 11 при том же пике
среднеквадратичное на два децибела выше, и это слышно как разницу в
плотности.
